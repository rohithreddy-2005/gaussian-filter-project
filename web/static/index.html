The Image is Numbers

A. Plain-English Concept

A digital image is a two-dimensional grid of numerical samples where each pixel stores three 8-bit integers ranging from 0 (black) to 255 (maximum brightness) representing Red, Green, and Blue light intensities.

B. Formula & Symbol Legend
I(x, y, c) ∈ {0, 1, 2, …, 255}   |   c ∈ {Red, Green, Blue}
In words: The intensity of the image at horizontal column x, vertical row y, and color channel c is an unsigned 8-bit integer between 0 and 255.

Step 2 of 6

Add Noise

A. Plain-English Concept

Noise simulates unwanted sensor variations by adding random Gaussian fluctuations or impulse dropouts to each pixel and clamping the resulting intensities to the valid hardware range of 0 to 255.

B. Formula & Symbol Legend
Inoisy(x, y) = clip(Iclean(x, y) + N(x, y), 0, 255)   |   N ∼ N(μ, σn2)
In words: The degraded noisy pixel equals the original clean value plus a normally distributed random perturbation, clamped strictly to stay between 0 and 255.
Symbol Mathematical Meaning Current Demo Value
Iclean Original pristine pixel intensity Range [0, 255]
N Random noise sample drawn from distribution Gaussian perturbation
μ Mean of the noise distribution (systematic bias) μ = 0.0
σn Noise standard deviation (controls noise spread/amplitude) σn = 50.0
clip(v, 0, 255) Clamping function: max(0, min(255, v)) Enforces unsigned 8-bit dynamic range
Seed Pseudo-random generator seed; identical seed yields identical noise field Seed = 42 (Reproducible)

Step 3 of 6

Build the Kernel

A. Plain-English Concept

The Gaussian filter kernel is a symmetric square window of weights shaped by a 2D Gaussian bell curve and normalized to sum to exactly 1.0000 so the total image brightness remains unchanged.

B. Formula & Symbol Legend
σblur = 0.3 × ((k − 1) · 0.5 − 1.0) + 0.8
G(x, y) = exp(−(x2 + y2) / (2σblur2))   |   w(x, y) = G(x, y) / ∑u,v G(u, v)
In words: The blur spread σ is automatically determined by kernel diameter k. Raw exponential weights decline with squared distance from the center, and dividing each weight by the sum gives normalized weights that sum to 1.0.
Kernel Size (k) Radius (r) Auto-Sigma (σblur) Formula Calculated Value Smoothing Behavior
3×3 1 0.3 × (0 − 1) + 0.8 0.80 Minimal smoothing, sharpest edges
★ 5×5 2 0.3 × (1 − 1) + 0.8 1.10 Optimal denoising & edge balance
7×7 3 0.3 × (2 − 1) + 0.8 1.40 Strong smoothing, subtle edge blur
9×9 4 0.3 × (3 − 1) + 0.8 1.70 Heavy smoothing, noticeable softening
C. Worked Example (Active Kernel Weights)
Kernel: 5×5 Window · σblur = 1.100
Center Weight (x=0, y=0): G(0, 0) = exp(0) = 1.0000 → Normalized: 1.0000 / 7.3225 = 0.1366
Corner Weight (x=2, y=2): G(2, 2) = exp(−8 / 2.42) = 0.0367 → Normalized: 0.0367 / 7.3225 = 0.0050
✓ Sum of weights = 1.0000 (Exact OpenCV cv2.getGaussianKernel)

Because the 2D Gaussian is circularly symmetric, 2D convolution equals two successive 1D passes: G(x, y) = G1D(x) · G1D(y).

Step 4 of 6

Slide, Multiply, Add (The Core Step)

A. Plain-English Concept

For each pixel in the image, the filter window centers on that pixel, multiplies each neighboring intensity by its Gaussian weight, sums the products, and rounds to the nearest integer.

B. Formula & Symbol Legend
O(i, j) = round &Biggl( ∑u=−rr ∑v=−rr w(u, v) · I(i + u, j + v) &Biggr)
In words: The filtered pixel at coordinate (i, j) is the weighted sum of neighboring pixel intensities within radius r, rounded to the nearest integer.
Symbol Mathematical Meaning Rule / Implementation
O(i, j) Filtered output pixel intensity Bounded to unsigned 8-bit [0, 255]
w(u, v) Normalized Gaussian kernel weight at displacement (u, v) Precomputed via cv2.getGaussianKernel (Step 3)
r = (k − 1) / 2 Neighborhood radius: 1 (3×3), 2 (5×5), 3 (7×7), 4 (9×9) Radius r = 2 (5×5)
BORDER_REFLECT_101 Mirror reflection when (i+u, j+v) falls outside image boundary The edge pixel itself is NOT repeated (e.g. c, b | a, b, c)
Symmetry Note: The 2D Gaussian function is radially symmetric (w(u, v) = w(−u, −v)), so spatial cross-correlation produces the exact same numerical output as true mathematical convolution (flipping the kernel).

Step 5 of 6

Measure the Result (MSE & PSNR)

A. Plain-English Concept

Filter performance is evaluated quantitatively by calculating the Mean Squared Error (average squared difference from the original) and Peak Signal-to-Noise Ratio (fidelity in decibels).

B. Formula & Symbol Legend
MSE = (1 / (H · W · C)) ∑x,y,c &bigl[ Iclean(x, y, c) − Ifiltered(x, y, c) &bigr]2
PSNR = 10 · log10 &Biggl( \frac{2552}{MSE} &Biggr)  dB
In words: MSE averages the squared intensity errors across all pixels; PSNR measures how many decibels the maximum signal power (2552 = 65025) exceeds this mean squared noise. Lower MSE is better; higher PSNR is better.
Symbol Mathematical Meaning Value in Current Pipeline Run
H, W, C Image Height, Width, and Color Channels (C=3 for RGB) 512 × 512 × 3
2552 = 65025 Maximum possible squared signal power for 8-bit unsigned images Constant: 65,025
MSE Mean Squared Error (average squared difference from clean reference) Lower is better (0 = identical)
PSNR Peak Signal-to-Noise Ratio (fidelity in decibels) Higher is better (>25 dB is good restoration)

Step 6 of 6

Choose Kernel Size (The Turnover Principle)

A. Plain-English Concept

Bigger kernels remove more noise but blur more detail, so the optimal kernel is found at the turnover point where noise reduction is maximized before edge blurring damages image fidelity.

B. Principle & Multi-Kernel Trade-off
k* = argmaxk ∈ {3, 5, 7, 9} PSNR(k)
In words: The optimal kernel diameter k* is the window size that maximizes PSNR. Below this point, noise suppression is incomplete; above this point, edge blurring damage exceeds noise reduction, causing PSNR to turn over and decline.
Kernel Size Heuristic σ Filtered MSE Filtered PSNR Gain vs Noisy Restoration Behavior
C. Worked Example (Turnover Analysis)
Turnover Identification: PSNR rises from 22.57 dB (3×3) to peak at 26.65 dB (5×5), then drops to 26.05 dB (9×9).

The 5×5 kernel reduces MSE by over 93% with optimal noise suppression. Increasing to 7×7 or 9×9 causes the low-pass filter to smooth true high-frequency image textures (edges, hair, fabric), producing net fidelity loss.

CS-305 Computer Vision — Gaussian Filter Reference Sheet

Mathematical Formulations, Derivations, and Quantitative Evaluation

1. 2D Discrete Image Representation

I(x, y, c) ∈ {0, 1, 2, …, 255},   x ∈ [0, W−1],   y ∈ [0, H−1],   c ∈ {R, G, B}

Images are 2D arrays of 8-bit unsigned integers (256 discrete levels per channel). Grayscale luminance is computed via ITU-R BT.601: Y = 0.299R + 0.587G + 0.114B.

2. Additive Noise Degradation Models

Gaussian (AWGN):   Inoisy(x, y) = clip(Iclean(x, y) + N(x, y), 0, 255),   N ∼ N(μ, σn2)
Salt & Pepper:   P(Inoisy = 0) = d / 2 (Pepper),   P(Inoisy = 255) = d / 2 (Salt)

Where clip(v, 0, 255) = max(0, min(255, v)) enforces unsigned 8-bit dynamic range boundaries.

3. Gaussian Kernel & Auto-Sigma Scaling Rule

σblur = 0.3 × ((k − 1) · 0.5 − 1.0) + 0.8

Heuristic scaling for odd kernel sizes: 3×3 → σ = 0.80, 5×5 → σ = 1.10, 7×7 → σ = 1.40, 9×9 → σ = 1.70.

4. 2D Gaussian Function & Unity-Gain Normalization

G(x, y) = exp(−(x2 + y2) / (2σ2)),   w(x, y) = G(x, y) / ∑u,v G(u, v)

Kernel weights are normalized so ∑u,v w(u, v) = 1.0000, guaranteeing unity gain and preserving overall scene brightness.

5. Linear Separability & Computational Complexity

G(x, y) = G1D(x) · G1D(y) = exp(−x2 / 2σ2) · exp(−y2 / 2σ2)

Separable 2D convolution reduces computational complexity from O(K2) to O(2K) operations per pixel, enabling real-time performance.

6. Spatial Convolution & Border Extrapolation

O(i, j) = round &Biggl( ∑u=−rr ∑v=−rr w(u, v) · I(i + u, j + v) &Biggr),   r = (k − 1) / 2

OpenCV utilizes BORDER_REFLECT_101: mirror reflection without repeating the edge pixel itself (e.g. c, b | a, b, c). Due to radial symmetry (w(u,v) = w(-u,-v)), cross-correlation equals true convolution.

7. Quantitative Fidelity Metrics (MSE & PSNR)

MSE = (1 / (H · W · C)) ∑x,y,c [ Iclean(x,y,c) − Ifiltered(x,y,c) ]2
PSNR = 10 · log10(2552 / MSE) dB = 10 · log10(65025 / MSE) dB

Lower MSE indicates smaller reconstruction discrepancy. Higher PSNR indicates stronger signal fidelity relative to residual noise.

8. The Over-Smoothing Turnover Principle

Noise reduction improves with kernel size up to an optimal window size (5×5 for σn=50 AWGN). Past this turnover point, high-frequency edge attenuation dominates over noise elimination, causing PSNR to decrease.
